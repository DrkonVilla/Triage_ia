# Flujos Clínicos

## Flujo de Triaje

1. Registro Paciente → 2. Captura Signos → 3. Evaluación IA → 4. Validación Enfermera → 5. Cola Médica

## Flujo de Atención Médica

En Espera → Llamar → Llamado → Atender → En Atención → Finalizar → Atendido

## Máquina de Estados

- **En Espera** → Llamado, Devolver (requiere justificación)
- **Llamado** → En Atención, En Espera
- **En Atención** → Atendido (requiere diagnóstico final)
